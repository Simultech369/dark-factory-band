# Pocketful Clean-Room Payment Engine

Pocketful is a small Venmo-like payment ledger generated by Dark Factory.
It is not a bank, wallet custody layer, chain integration, or production
financial system. It demonstrates deterministic cents accounting, split
payment rounding, and concurrent transfer safety in a local Python package.

## Run

```bash
python -m ruff check .
python -m pytest --basetemp=.pytest_tmp -q
```
